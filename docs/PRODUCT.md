# Daynote — product direction

**Promise:** Keep more of your life without turning journaling into another chore.

The central loop is **capture → review → save → reflect → rediscover**. Voice is the primary entry point, with writing, photos and videos one tap away. Saving and submitting to Gemini are explicit, separate actions where media is involved.

The interface uses midnight blue (#090E18), layered navy (#101725), periwinkle (#A8BAFF), warm off-white, and a restrained lime microphone accent (#D3ED98). Typography is light and editorial. The layout gives the recorder visual priority; it avoids fake dashboards, streak pressure and decorative metrics.

## Original enhancements

1. **A living memory collection.** Searchable, tagged text and media memories with favourites and on-this-day resurfacing.
2. **Voice with a review step.** Record, listen, save privately, request transcription, edit the result, then commit it. Recording alone sends nothing.
3. **Explainable personal ideas.** Explicit interests plus recent journal words shape optional activities and reflection prompts; supporting memories remain one click away.
4. **Monthly and annual stories.** Actual counts accompany Gemini themes and narrative. Recaps are private, idempotent, exportable and grounded in source memories.
5. **Reflection with context.** Open any memory or recap in a new multi-turn conversation; the server only retrieves the signed-in user's selected sources.

## Deliberately deferred

Live duplex Gemini voice chat, automatic scene/video analysis, background uploads, push notifications, shared journals, native mobile apps and fully bundled media exports. Browser speech playback is available for completed Gemini replies; it is not a Gemini Live API session.
